# Sageroom 隐私政策

**生效日期：2026 年 11 月 25 日**

Sageroom（以下简称"本软件"）是一款本地优先的桌面 AI 群聊应用。本政策说明本软件如何处理数据，以及你享有哪些权利。

本政策依据《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》等法律法规制定。

## 一、核心原则

本软件采用**本地优先**设计：

- **不收集你的个人信息。** 本软件没有账号体系，不要求你提供姓名、手机号、邮箱、身份证件、地理位置等个人身份信息。
- **数据默认保存在你的设备上。** 聊天记录、智能体配置、人格与经历、头像、偏好设置均存储在你本机的数据目录，由你完全掌控。
- **没有统计与崩溃上报。** 本软件不嵌入产品分析、广告或崩溃上报 SDK，不收集设备标识符、使用行为或错误日志。
- **不上传、不出售、不共享你的数据。** 本软件没有自己的服务器，不会把你输入的对话内容或本地文件上传到任何由我们运营的服务。

## 二、本地数据

本软件在本机保存以下数据：

| 数据 | 内容 | 用途 |
| --- | --- | --- |
| 聊天数据 | 房间、消息、引用关系 | 展示群聊记录 |
| 智能体数据 | 名称、头像、个人介绍、人格维度、经历、模型配置 | 驱动角色对话 |
| 用户数据 | 昵称、头像 | 展示你自己的身份 |
| 偏好设置 | 主题、动画、关闭行为、发送键、未读进度 | 记住你的使用习惯 |
| 密钥引用 | 系统凭据库中的引用标识（不含密钥明文） | 复用你配置的模型服务 |

你可以随时通过设置中的"数据"分类查看数据目录、迁移到其他位置。删除数据目录即可清除全部本地数据。卸载软件不会自动删除这些数据，便于重装后继续使用。

## 三、关于智能体与"我的"数据

本软件中的**智能体角色、人格设定、经历、个人介绍、聊天内容都可以由用户自行设定、修改或杜撰**：

- 智能体是角色扮演性质的对话对象，不是真实自然人，其身份、性格、经历、观点均为可编辑的创作内容。
- "我的"资料同样由你自行填写，你不需提供真实身份信息，可以使用昵称、虚构身份或任意文字。
- 本软件不会核验、推断或要求这些内容与现实身份一致，也不会将其用于身份识别。

请勿在对话中输入真实的敏感个人信息（身份证件号、银行卡号、住址、联系方式等）。虽然这些数据默认只保存在本机，但一旦你启用云端模型，发送的内容会到达你所选的服务商。

## 四、第三方服务

### 4.1 模型服务

本软件支持配置模型服务以生成对话。当你启用某个模型时：

- 对话上下文（包括聊天内容与人格设定）会发送给你所配置的服务商，以完成模型请求。
- 这一步由你主动配置并触发，本软件仅作为客户端转发，不经由我们运营的服务器。
- **API 密钥保存在操作系统的凭据库中**，不会写入本地配置文件，也不会随数据目录迁移或上传。

服务商可能依据其自身隐私政策处理你发送的内容。请参考对应服务商的隐私政策。你的数据流向与费用取决于你选择的服务与配置。

### 4.2 联网新闻

本软件支持可选的联网新闻能力。启用后，会根据对话需要向新闻数据源发起查询。相关配置与密钥由你提供，密钥同样保存在系统凭据库中。

### 4.3 第三方组件

本软件使用的开源组件与依赖按各自许可证分发。本软件不通过第三方 SDK 收集你的个人信息。

## 五、权限

本软件仅申请实现功能所必需的系统能力：

- **本地文件读写**：用于读取与保存数据目录、导入头像。
- **系统凭据库**：用于安全保存你配置的 API 密钥。
- **网络访问**：仅在你配置并启用模型服务或联网新闻时使用。

这些能力由应用内部按需调用，不请求与功能无关的系统权限。

## 六、你的权利

由于本软件不收集你的个人信息，不涉及向第三方提供或跨境传输你的个人信息。对于保存在你本地的数据，你拥有完全的控制权：

- **查阅与导出**：可查看数据目录并迁移到其他位置。
- **更正与删除**：可自行编辑或删除智能体、消息、经历等本地数据。
- **撤回**：可随时关闭模型服务、联网新闻，或清除已配置的密钥。
- **停止使用**：卸载软件并删除数据目录即可终止全部本地数据处理。

如需就本政策提出问题，可通过下方联系方式与我们联系。

## 七、儿童隐私

本软件面向成年用户，不面向 14 周岁以下儿童，不会主动收集儿童个人信息。

## 八、安全

本软件采取合理措施保护数据安全：密钥不落盘、数据默认留在本机、不嵌入统计 SDK。但请理解，任何软件都无法保证绝对安全，请自行妥善保管设备与数据目录。

## 九、政策更新

当数据处理方式发生变化时，我们会更新本政策并修改生效日期。重大变更将通过应用内提示告知你。
