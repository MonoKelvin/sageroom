# Sageroom 界面与交互详细设计

> 版本：0.5｜状态：黑白毛玻璃与即时应用设置已实现，完整 V1 交互仍为规划｜日期：2026-11-20\
> 当前基线为聊天、智能体、设置、用户四个保活页面；模型连接测试不等于智能体运行。实机证据与未覆盖平台见 [10](10-测试验收与性能评估.md)。功能基线见 [02](02-用户需求与产品规格.md)，参数基线见 [00](00-文档导航与确认清单.md)。

## 1. 设计目标与风格

### 1.1 主题：安静但有生活感的群聊

界面应该让人先注意“谁说了什么”，而不是注意 AI 状态卡、模型名称和功能宣传。浅色以白与中性灰为背景、黑色为文字/图标/主要按钮，深色基底为 `#151517`、白色承担主要操作，不使用纯黑背景。紫蓝仅用于链接、结构化提及和少量特殊提醒，不用于普通按钮、导航选中或本人气泡。固定面板采用同一套半透明毛玻璃、微弱边缘高光与层级留白；正文保持稳定可读，不给虚拟消息逐项叠加 blur，也不把 CSS 毛玻璃宣称为桌面后方的 OS 材质。

- 聊天是主体，不做多列控制台、满屏 Agent 卡片或能力仪表盘。
- 桌面采用左侧图标导航、对象列表与弹性聊天卡片；窄视口折叠列表而不是整体缩小字体。
- 技术信息进入设置和诊断，聊天区只呈现对用户有意义的状态。
- 无回复和安静是正常体验，不显示“没有人回答你，请重试”的催促。
- 群主在聊天视觉地位上与普通成员相同；标记只提示群管理权限。
- 毛玻璃用于标题栏、输入区或弹层，不对整个历史消息逐项施加 blur。

### 1.2 建议设计 token

以下用于第一版设计评审，颜色必须在实际透明背景合成后校验对比度。

| Token | 浅色建议 | 深色建议 | 用途 |
|---|---|---|---|
| `surface.canvas` | `#F1F1F3` | `#151517` | 工作区背景 |
| `surface.content` | `#FFFFFF` | `#242427` | 稳定可读区域 |
| `surface.chrome/glass` | 白色约64～70% | 同系深灰约64～76% | 固定面板、标题栏 |
| `text.primary/primary` | `#000000` | `#FFFFFF` | 主要文字、图标、按钮和焦点 |
| `primary.foreground` | `#FFFFFF` | `#151517` | 主按钮反色内容 |
| `text.secondary` | `#67676E` | `#B4B4BC` | 日期、来源、辅助说明 |
| `semantic.accent` | `#353878` | `#C3C5ED` | 少量链接/提及/特殊语义，深色提高可读性 |
| `surface.self` | `#E7E7EB` | `#333337` | 本地用户消息 |

状态不能只靠颜色区分；图标、文字和屏幕阅读器标签共同表达。

| 类别 | 建议值 |
|---|---|
| 中文字体 | Windows 优先 `Microsoft YaHei UI`，fallback `Microsoft YaHei` / 系统 sans-serif；不运行时下载字体 |
| 拉丁文字 | `Segoe UI` 与系统字体；与中文正文统一节奏 |
| 代码 | `Cascadia Code` / `Consolas` / monospace，只用于代码与必要技术字段 |
| 正文 | 14px，行高 1.55；设置正文 14～15px |
| 标题 | 主窗口 14～15px semibold；设置页标题 20px |
| 辅助文本 | 12px；重要错误和状态不能仅用微小文字 |
| 间距 | 4px 基础，常用 8/12/16/24px |
| 圆角 | 工具按钮 8px；气泡 14px；输入区 16px；主要弹层 20px |
| 阴影 | 固定工作区/卡片/设置分区不加装饰性投影；仅悬浮菜单/提示和窗口外缘保留必要阴影，最大化去窗口投影 |
| 图标 | Tabler Icons，常规 18px/20px，统一 stroke；纯图标按钮必须有名称 |

“多圆角少边框”不等于取消输入边界、焦点环或错误状态；这些是功能信息。

## 2. 信息架构

```text
应用外壳（自定义标题栏，右上仅最小化 / 最大化或还原 / 关闭）
├─ 聊天
│  ├─ 真实单群对象列表，group/direct adapter 类型保留扩展点
│  ├─ 群名称、真实消息、虚拟历史窗口与保活草稿
│  └─ 卡片内搜索与群信息面板
├─ 智能体
│  ├─ 列表顶部全局配置：模型、人格预设、默认运行偏好
│  └─ 成员独立资料、角色指令（SKILL）、模型快照、偏好
├─ 设置
│  ├─ 外观与减少动画
│  └─ 版本、许可、数据目录及占用、开源与作者、明确退出
└─ 用户
   ├─ 本人昵称、简介与本地头像
   └─ 聊天风格、频率、关注和自我分析保留受控 section 注册；未接入项不渲染空占位卡
```

引用、结构化提及、完整附件/通告/群参数编辑、工具授权、运行/通知/记忆等仍为后续 V1 交互，不把未来菜单或类型当成当前可用入口。

不在主聊天列表显示每次决策日志、token 计数或工具的每个内部步骤。

## 3. 窗口规格

### 3.1 主窗口

初始窗口 `1100 × 780` DIP，最小 `860 × 620`。导航 rail 72px，对象列表约 240px，主要卡片弹性布局。小视口和 200% WebView 缩放折叠对象列表、保留页面内滚动，不整体缩小文字；系统 DPI 与 WebView 缩放是不同验收项。

```text
┌ 品牌图标 Sageroom                                  − □ × ┐
│ 聊天 │ 聊天对象       │ Sageroom                  搜索 / 群信息 │
│ 智能 │ Sageroom       │                                        │
│ 设置 │                │              真实消息                  │
│ 用户 │                │                                        │
│      │                │ 消息输入                        发送   │
└──────────────────────────────────────────────────────────────┘
```

- 正常窗透明、无原生标题栏，自绘 16 DIP 留白、20 DIP 圆角与轻阴影；Rust 命中区域按实时 client rect / 原生 DPI 计算。
- 最大化仅移除自绘留白、圆角和阴影并铺满工作区，保留自定义标题栏；不恢复系统标题栏、不进入真正 fullscreen。
- 最大化状态来自首次 getter 和原生 resize 后重读，覆盖按钮、标题栏双击和系统路径；WebView 缩放不改变原生窗口轮廓的 DIP 命中区域。
- 群名省略但保留完整名称提示，正文有合理阅读宽度；拖窗只在非控件标题区域触发。
- Win10/Win11、系统 DPI 与原生点击穿透等实际覆盖范围见 10，不能只凭 CSS 或几何单测声明全平台验收。

### 3.2 设置与业务页面

设置在同一窗口内通过导航进入，不再创建独立设置窗。聊天、智能体、设置、用户均保持已激活内容挂载，隐藏页不可聚焦、不响应当前页快捷键；切换保留草稿、失败请求 ID 与历史阅读窗口。新群/私聊和新业务页通过受控编译期注册接入，不允许任意下载执行插件。

表单、确认和错误优先使用卡片内分区；头像文件选择使用原生受限选择器，危险动作采用内联确认。

设置页优先表单、列表和清晰分区，不把每个字段包装成一张大卡片。危险动作独立放在页尾并有明确说明。

## 4. 聊天列表规范

### 4.1 消息构成

- 昵称和头像从消息发送时快照显示；头像可点击查看当前成员，但改名不重写历史。
- 自己的消息右侧，其他成员左侧。智能体群主不使用特殊大气泡或上级视觉样式。
- 相邻同一发送者且时间接近时可弱化重复昵称，不能隐藏引用及附件来源。
- 正文允许文本选择；无语义的头像、按钮和 chrome 不导致误选。
- 时间分界和精确时间是两种信息：时间分界可稀疏，单条时间在详情/hover/焦点时可看。
- 消息错误状态留在原位，重试不生成重复消息。
- 长代码折叠，支持复制与展开；不自动执行。
- 外部链接点击由用户触发，展示目标域名；禁止自动加载远端嵌入媒体和跟踪像素。

### 4.2 滚动与未读

| 场景 | 行为 |
|---|---|
| 当前在底部 | 新消息自动保持底部，图片尺寸变化也保持稳定 |
| 上翻阅读 | 保持阅读锚点，显示新消息计数按钮，不自动跳转 |
| 加载更早消息 | 插入到前方后保持原消息相对视口位置 |
| 搜索定位 | 请求目标序号周边记录、定位并短暂高亮，不加载整个历史 |
| 新消息到达且主窗无焦点 | 增长未读，不标记已读 |
| 主窗有焦点但读旧消息 | 只推进从既有未读边界连续浏览到的已读水位，不把底部未读全部清零 |
| 搜索/引用跳到未读区中部 | 不跨越前方未读缺口推进水位；首版不追踪离散单条已读 |
| 点击“回到最新”或“标记已读” | 用户明确将快照最新水位及以前标记已读；不宣称跳过内容均已逐条阅读 |
| 消息撤回 | 当前项原位变占位，尽量保持高度过渡，不把列表跳到别处 |

虚拟列表只渲染可见项与必要 overscan。读屏支持不能简单把历史全部丢进 live region；建议只播报新消息摘要，并提供“暂停自动播报”。

### 4.3 引用和提及

- 输入区引用条显示发送者和一行正文，可取消。
- 点击消息引用跳转原消息；不存在、过期、撤回时给出明确占位。
- `@` 菜单按昵称/别名搜索，显示头像、类型和唯一 ID 的短标识以区分重名。
- 文本中手工输入“@Sage”不等于结构化提及；选择菜单后才建立实体引用，发送前允许识别建议。
- 当前群主可选择“所有人”，其他成员不能通过复制文字伪造此权限。
- @所有人只是通知与接收者标记，不保证成员发言；不显示“强制全体回复”。
- 名称和提及选中后的实体在编辑过程中必须保持一致，剪切/删除不能留下隐形收件人。

## 5. 输入区与媒体

### 5.1 文本输入

- Enter 发送，Shift+Enter 换行；IME 组合态 Enter 优先确认输入。
- 空白文本且无附件时禁用发送；不把多行纯空白生成消息。
- 多行输入高度自适应到建议 160px，其后内部滚动。
- 发送中的草稿有本地 request ID；成功清理对应草稿，新输入内容不受旧请求成功影响。
- 粘贴纯文本不自动解释为指令；长文本超限时提示拆分或作为文件发送。
- 未发送草稿不进入模型上下文；输入仅更新本地交互状态，不按每次按键触发付费语境检查，也不随机停止所有成员。已提交新消息的候选重判按 04 执行。

### 5.2 附件流

```text
选择/拖放/粘贴 → 本地暂存与检查 → 输入区预览 → 发送事务 → 聊天附件 → 按需视觉上传
                         └ 超限/危险格式 → 明确错误，原文件不受影响
```

- 预览明确标注图片/文件类型、原文件名、大小；多附件逐项可移除。
- 不在前端持有整个大文件的 base64；使用受限句柄或对象 ID。
- 列表缩略图有固定占位宽高，减少解码后抖动。
- 原图查看弹层支持缩放/适应/另存；Esc 关闭、焦点返回触发消息。
- GIF 默认可见时播放；离屏暂停，减少动画模式显示首帧。
- 文件点击展示“打开/另存”的显式选择，不自动启动脚本/可执行程序。
- 上传给模型由授权和请求构建控制，不能因图片已在聊天显示就认为用户已同意向所有提供方外传。

### 5.3 表情面板

Tabs：emoji、颜文字、内置表情包、收藏表情。支持搜索、最近使用、收藏管理。内置表情包需有实际静态/GIF 资源及可分发许可，不能把空收藏面板作为交付。无系统 emoji 字体时提供合理文本/选择器降级，不从不明网站自动下载图片。

收藏表情新增必须来源清楚；删除收藏只移除收藏引用，仍被聊天或任务引用的文件不立即删除。内置资源必须记录来源与许可。

## 6. 成员状态与工具任务

### 6.1 对用户展示的成员状态

| 状态 | 文案建议 | 说明 |
|---|---|---|
| Ready/Observing | 在群里 | 具备运行条件，未必正在付费调用 |
| Sleeping | 暂时离开 | 模型安排的休息，不等于应用错误 |
| Paused | 已暂停 | 本地用户显式暂停 |
| NeedsConfiguration | 需要配置 | 缺模型/凭据/能力 |
| AwaitingApproval | 等待授权 | 正等待用户决定具体工具操作 |
| ToolRunning | 正在处理任务 | 任务面板提供细节 |
| Protected | 达到运行限额 | 硬保护阻止，不伪装成沉默 |
| ErrorBackoff | 正在重试连接 | 有界重试期间，可取消/查看原因，不反复响铃 |
| Offline | 已离线 | 重试耗尽/确定故障；可打开诊断、换模型及重试上线 |

“正在输入”仅在模型已经决定发言、合法草稿等待发布时短暂展示。模型尚在评估是否回复时，不制造一定有回复的预期。不展示“思维链”或持续跳动的全体思考动画。

离线故障周期显示一次小标记“「Sage」已离线”，不是大错误气泡；昵称为当时实际快照。点击标记或头像进入当前成员详情的“诊断 → 配置模型 → 重试上线”。失败原因脱敏，区分余额、认证、限流、超时、无效输出；删除成员后仍可查看历史标记，不误跳同名成员。

默认状态小标记不增加聊天未读、声音或系统通知，可配置一次离线提醒；retry 进度只更新状态。小标记不触发其他成员模型调用；成功上线后旧标记保留为历史，当前头像状态更新。此默认属于 Q-04/通知策略待确认项。

### 6.2 工具任务卡

任务卡附着于委托消息或工具成员详情，只显示必要状态：

- 等待授权：任务摘要、提供方、数据外传范围、费用估计/未知、允许一次/拒绝。
- 排队：任务类型、队列位置的可选显示、取消。
- 执行：开始时间、简明阶段、取消；不使用伪造精确进度。
- 完成：结果消息、来源/附件入口。
- 失败：具体类别、可重试条件；非幂等请求不提供误导的一键无限重试。
- 结果未知：说明可能已执行或计费，优先查询远端任务，不自动重发。
- 取消：区分停止本地等待和远端确认取消。

普通聊天结果仍是气泡；内部工具 JSON、搜索原始网页和请求日志不进入聊天主列表。

## 7. 群管理交互（已纠正的群主语义）

### 7.1 群名称与群参数

- 当前群主拥有“编辑群资料”入口，只能改已确认字段。
- 智能体群主通过受限动作提交修改；聊天里显示可追溯的变更信息，而非把模型执行任意设置命令。
- 不将模型、成员 SKILL、费用、安全配额、密钥、存储路径或工具权限混入群参数。
- 建议候选字段为群头像、群简介等展示元数据；是否包含这些字段仍需用户确认。
- 修改有版本冲突反馈；不会覆盖用户正编辑的更高版本。

### 7.2 通告

- 发送通告包含标题及正文；只有当前群主能以通告类型提交。
- 可在群资料查看历史通告；主聊天出现普通可引用的通告消息。
- 通告显示作者和时间，保留智能体身份，不显示为应用 system 提示。
- 默认不自动叠加 @所有人；群主需要显式选择。
- 通告不成为其他智能体的高优先级指令、不强制接话，不改变其他成员权限。
- 通告不原地修改；作者仍可在不足 120 秒时按 chat_recall 撤回自己的通告，需要更正则发新通告，保留可追溯历史。

### 7.3 本地应用管理与群内身份

用户可以管理应用和指定群主，这不等于以普通群成员身份伪造当前群主的通告。若群主是智能体，用户仍有“将群主设为自己”的应用管理操作；普通聊天中没有管理员必答效果。

## 8. 设置页详细规格

### 8.1 我的资料与成员编辑

我的资料是独立导航入口，成员编辑在智能体页进行。设置按分区采用 key-value 行：左侧标题及短副标题，右侧控件；窄视口转为纵排。单行文本使用独立编辑组件，输入中只改变本地草稿，失焦或 Enter 应用、Escape 还原；多行文本框内右下角提供对勾/叉号，对勾或焦点离开整个编辑区域应用，叉号还原本次编辑前值且不先触发失焦写入。文本框与内部按钮间的键盘转焦不提交，IME Enter 不误应用。无改动不发 IPC；失败保留内容，迟到回执不覆盖新编辑。昵称、头像和简介不改变稳定 ID，也不重写历史消息。聊天 Composer 的 Enter 发送语义独立，绝不失焦自动发送。

成员编辑建议按四个子区域布局，而不是超长无序表单：

1. 身份：昵称、头像、类型、可选性别描述、简介、称呼。
2. 性格与 SKILL：选择预设、维度解释、可编辑文本、有效提示词预览。
3. 模型：选择全局预设副本、显示来源版本、独立覆盖字段和共享凭据说明。
4. 运行与工具：启用、记忆、允许能力、预算、复杂工具任务 thinking、自主资料修改开关/字段及变更记录。

普通下拉、checkbox/switch、头像选择成功立即应用并自动持久化；数字键入按文本完成时机校验，步进操作直接应用。不再提供整页保存/重新读取/离开未保存表单确认。已应用值与未确认文字草稿分开，全局预设及凭据使用串行版本协调，成员/用户/外观按资源隔离写入，成功只在 COMMIT 后确认。冲突或写入失败停该资源并保留内容，例外恢复可“重试应用”或“撤销本次应用”，不盲目覆盖服务端同字段。创建/复制预设直接落库，允许真实未配置模型对象，非空 URL 仍严格校验；删除和会覆盖独立参数的模板采用须明确确认，确认后直接生效。

### 8.2 模型与凭据

- Provider、协议和模型 ID 分开；OpenAI-compatible 地址不自动判定全部能力。
- API Key 使用独立 password 文本组件，非空输入失焦后写入系统凭据库并清空；不逐字创建对象、不读回密钥。空白编辑不自动删除，解绑需要明确操作；未知写入结果不自动重复写新对象。
- Base URL 明确说明 HTTPS 和自定义内网服务边界；不能默默上传到改过的未知域名。
- 显示结构化输出、工具、视觉、thinking 控制为已验证/声明支持/未知/不支持。
- 测试可能收费，分别测试连通、文本和必要能力，不偷偷发送用户最近聊天。
- 价格配置包含币种、单位、缓存/思考字段及资料日期；未知不是 0。

### 8.3 运行与预算

- 全部暂停位于易发现的位置，可从托盘访问。
- 自动唤醒开关、静音时段、运行保护与成本是不同设置。
- 展示成员数量放大成本的解释和当天调用分类。
- 数额预算必须显示币种，跨币种不直接相加；默认值见 [00](00-文档导航与确认清单.md)。
- 调整预算不绕过保护；预算耗尽时有主动恢复操作。
- 显示“隐藏到托盘继续运行”和“锁屏时暂停主动活动”各自行为；开机启动为 P2 可选，不作为完整 V1 必备设置。

### 8.4 数据与记忆

- 显示当前数据目录、磁盘空间、分类占用和最近有效备份。
- 迁移前选择目标、估计容量、显示将暂时暂停运行、确认保留原目录。
- 备份按钮生成可恢复快照；导出按钮提供可读格式，二者不得同名。
- 导入先显示校验结果、恢复影响及默认恢复资源上限；超限备份须预告所需维护参数，不能先报告成功再到恢复时才报无法接受。
- 同安装恢复显示“保留恢复前已用额度/未知收费”；跨设备显示历史账本不等于当前账户余额，成员保持暂停等待重新确认。
- 切根后重取聊天/成员/未读快照，旧搜索、引用确认和未发送草稿不自动重发到恢复库。
- 清理缓存不提示会删除聊天；清理原附件必须列出影响消息和仍受收藏保护的对象。
- 记忆管理显示成员/群摘要、来源及更新时间，支持删除/纠正/禁用。
- “删除记忆”与“删除原始聊天”是两个动作；两者的第三方数据边界各自说明。

### 8.5 诊断

默认显示不含密钥与聊天正文的状态、请求类别、usage、错误码和追踪 ID。临时详细日志需用户明确开启并有有效期。导出诊断包前预览脱敏范围，不上传到任何服务。

## 9. 通知与托盘交互

| 事件 | 主窗正在读底部 | 主窗在看历史 | 隐藏/无焦点 |
|---|---|---|---|
| 普通成员消息 | 直接呈现，不响铃 | 新消息按钮，可配置轻提示 | 未读数和托盘变化 |
| 提及本地用户 | 高亮提及 | 新消息按钮与提及标记 | 按授权系统通知，遵守勿扰 |
| @所有人 | 同普通提及展示，但不强制应答 | 保持阅读锚点 | 可进入提及通知规则 |
| 工具完成 | 呈现结果 | 结果入口 | 按设置聚合一次提醒 |
| API 重试 | 不在群里制造消息 | 状态更新 | 默认不响铃 |
| 预算耗尽 | 明确运行状态 | 明确运行状态 | 可选一次非重复提醒 |
| 通告 | 通告入口/消息 | 不抢焦点 | 是否提醒取决于显式提及与设置 |

托盘菜单：打开聊天室、全部暂停/恢复、设置、退出。图标变化与徽标需要平台 PoC；不支持时使用固定未读图标和 tooltip 数量。减少动画时禁用闪烁，保留可识别未读状态。

系统通知正文默认隐藏的建议需确认；锁屏和系统勿扰的能力不由应用完全控制。应用不能为证明通知可达而绕过 OS 勿扰。

## 10. 动画规格

| 场景 | 建议动画 | 目的与限制 |
|---|---|---|
| 表情/提及弹层打开 | opacity + 小幅 scale，100～160ms | 表达层级，不从屏幕边缘飞入 |
| 弹层关闭 | opacity，80～120ms | 可中断，Esc 立即可用 |
| 输入区附件增加/移除 | 小范围布局过渡，120～180ms | 帮助理解高度变化，保持焦点 |
| 新消息进入 | 极轻 opacity，最多 120ms | 不对批量历史执行；不影响滚动测量 |
| 引用定位 | 短暂背景强调，约 800ms 淡出 | 提示位置，不摇动气泡 |
| 状态切换 | 图标/文本交叉过渡，约 100ms | 错误文案和按钮立即可操作 |
| 原图预览 | opacity/轻 scale，150ms 内 | 不持续缩放 backdrop blur |
| 托盘提醒 | 平台受控图标交替 | 限时、可关闭、减少动画则静态 |

以 CSS transition/原生动画完成基础交互；只有真实复杂编排才引入 Motion 等库。不要同时引入多个动画系统。避免大面积 blur 动画、逐帧 React state 更新、长列表 stagger 和一直旋转的装饰。

减少动画模式下去掉非必要位移/缩放，保留即时状态切换；不是把时长改成慢速。高频键盘触发的搜索、提及选择及弹层开关即时完成，不等待入场动画；鼠标触发的弹层从触发点做小幅过渡，进入使用 ease-out，退出更短且可中断。输入区高度变化以稳定滚动锚点为先，不用整列布局动画拖慢聊天。性能验收见 [10](10-测试验收与性能评估.md)。

## 11. 无障碍、键盘和文本

- 正文对比度至少 4.5:1；大字与必要非文本组件按对应标准检查。
- focus ring 必须可见，且不被毛玻璃或 overflow 裁切。
- 按钮可点击区域建议至少 32px，主要操作 36px；移动版未来另按触控重新设计。
- 所有弹层遵守焦点进入、trap（模态时）、Esc、关闭后返回规则。
- 主要快捷键建议：Ctrl+F 搜索，Ctrl+, 设置；是否启用 Ctrl+Enter 发送可配置。
- 快捷键不能覆盖输入法、系统快捷键或文本编辑默认行为。
- 文案以“暂停成员”“配置模型”“恢复备份”等动词说明下一步，不使用“操作失败”空话。
- 每个成员在身份详情可识别为智能体；自然交流不等于对用户隐瞒 AI 身份。
- 减少透明与高对比偏好提供实色/清晰边界；不依赖 OS/CSS 检测必然可用，设置中允许手动关闭透明。
- 主要操作在 pointer-down 就有视觉反馈，但提交在 click/正常激活时完成，拖离可取消；动画不能锁住输入或延后危险确认。
- 正文/设置采用可缩放布局，中文保持常规字距，不把西文展示标题的负字距全局施加到中文；放大字体时输入区和弹层仍可达。
- 进入/退出弹层保持同一来源锚点，快速关闭/重开不跳变；减少动画时即时切换，不把动画变慢。
- 模型输出中 Markdown 使用安全子集，不渲染任意 HTML。

参考依据：[W3C 对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[W3C 交互动画可关闭](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)，于 2026-11-18 查询。

## 12. 必须制作和验收的界面状态

| 页面/组件 | 必须覆盖 |
|---|---|
| 聊天 | 首次空群、未配置、安静、有未读、无焦点、长历史、发送失败、超长文本、同名成员 |

| 工具 | 待授权、排队、取消、结果未知、无来源、附件下载失败、重启恢复 |
| 数据 | 无备份、备份校验失败、磁盘满、跨卷迁移、导入缺附件/缺密钥、恢复回滚 |

| 通知 | 权限关闭、系统勿扰、普通/@/通告、锁屏隐藏预览、撤回、多消息聚合 |
