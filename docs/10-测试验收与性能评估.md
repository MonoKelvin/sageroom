# Sageroom 测试验收与性能评估

> 版本：0.6｜状态：聊天/经历核心及本地运行子场景已回归，完整 V1 验收仍待实施｜日期：2026-11-23\
> 功能来源：[02](02-用户需求与产品规格.md)；参数：[00](00-文档导航与确认清单.md)；实施阶段：[11](11-实施路线与开发任务分解.md)。本文定义应如何测试，不提供虚构的通过率、截图、性能或费用结果。

## 1. 验收分层

| 层 | 目的 | 方法 | 不可替代的事项 |
|---|---|---|---|
| 静态/合同 | DTO、schema、enum、文档与模块边界一致 | 类型检查、合同 fixtures、链接/引用检查 | 不证明真实 provider 支持 |
| 领域单元 | 权限、三分钟撤回期限、幂等、预算、状态和候选失效 | 可控时钟、确定性模型返回、故障注入 | fake 模型不用于证明自然度 |
| 本地集成 | SQLite、配置文件、附件、备份/恢复实际一致 | 实际临时 SQLite、真实文件 I/O 和中断恢复 | 不用 mock DB 替代关键事务测试 |
| Provider 合同 | 精确 endpoint/model/API version 能力 | 非敏感合成样本、真实 API、有限预算 | 必须先经用户批准付费与外传 |
| 桌面功能 | 安装态、托盘、窗口、IME、通知、后台 | 实际 Tauri 包和目标 Windows 设备 | 浏览器截图不证明原生能力 |
| 资源/压力 | 全进程树内存、长历史、检索、媒体、24h 运行 | 固定数据、release build、独立采样 | dev server 不作最终性能结论 |
| 自然度/记忆 | 独立成员、沉默、身份稳定、事实归属和召回 | 固定场景、多次运行、盲评、统计 | 单条好看回复不能证明长期效果 |

P0 和 P1 是交付顺序，不是减少完整 V1 验收范围。V1 完成前所有原文对应项均需达到完成标准。

## 2. 环境与记录格式

首要候选环境为 Windows 11；是否支持 Windows 10 19045 由 Q-01 确认，不以本机 OS 代表全部支持。Windows 10 的系统支持/安全更新状态也要在最终分发评审说明。

每次记录：测试 ID、应用 build/commit、依赖锁版本、OS 完整版本、CPU/RAM/存储、DPI/显示器、WebView2 Runtime、provider/model/API version、配置/SKILL hash、数据集 hash、预算/权限、运行命令、起止时间、结果、证据路径及异常。

状态枚举：NotRun / Passed / Failed / Blocked / NotApplicable。NotApplicable 需说明批准范围之外的原因；“没凭据”“没设备”是 Blocked，不是 Passed。

真实 API 报告脱敏，不附 key、鉴权头或私有思维链。合成记录不是生产数据；使用用户聊天样本须单独批准范围、外传和保留。

## 3. 基准数据集

| 数据集 | 内容 | 验证点 |
|---|---|---|
| D-01 空环境 | 无凭据、默认 Sage、空聊天 | 首启可管理，不假装模型已上线 |
| D-02 常规群 | 1/4/8 位成员，中文/英文/emoji、引用、重名及改名 | actor 隔离、显示与提及身份 |
| D-03 长历史 | 10 万文本消息，跨日期、密集引用、长短混合 | keyset 分页、搜索、内存不随全部 DOM 增长 |
| D-04 媒体群 | 静图/GIF/普通文件、过期/损坏/收藏和头像引用 | 动态高度、可见播放、解码与 GC |
| D-05 恶意输入 | JSON 越权、注入文本、异常 URL、ZIP 路径/链接、畸形 schema | 拒绝危险动作，不写越界文件 |
| D-06 记忆事实 | 带标准答案的自述/观点/事实/改口/同名/撤回来源 | 摘要归属、召回与失效 |
| D-07 故障过程 | 401/429/5xx、断流、磁盘满、提交前后崩溃、迁移中断 | 状态、预算、持久恢复和不重复收费 |

压力素材在应用控制的独立临时目录创建，恢复/恶意包在各自新空隔离目录处理；测试脚本与导入内容不共目录执行，解析不可信内容的 Python 使用 `-I`。不得拿用户实际 data_root 做破坏性故障测试。

## 5. Provider 合同矩阵

初始候选为一条用户实际 OpenAI-compatible、一条实际 DeepSeek、Anthropic 原生；用户未指定端点/预算时全部 NotRun。

每条记录文本、schema、tools、vision、tools+schema、off thinking、usage、stream、timeout、cancel、价格资料版本。只测被选择的必要组合；不支持的组合记录 Unsupported 并在 UI 阻止配置，不把它伪装为“没测试所以默认支持”。

付费测试先给出样本数、最大请求/输出/图片/搜索单位、预估费用/未知项和停止条件，用户批准后才运行；批准单次模型测试不批准全量聊天样本外传。

## 6. 性能口径与建议目标

### 6.1 参考环境与测量方法

候选参考设备：4 核以上 CPU、16GiB RAM、SSD、Windows 11、60Hz 显示器；最终填写实际型号。使用 release 安装包、固定 Runtime 与数据集，至少 5 次冷启动、30 次核心交互和一轮 24h 常驻。

资源测量包含 Tauri 主进程、关联 WebView2 子进程，GPU 使用另报；RSS/working set、private bytes/commit 分开，不能只报 Rust 进程。后台空闲状态需要标明可见/隐藏窗口、成员数量、计划和网络活动；主动模型请求不算无任务空闲。

### 6.2 目标表

以下用于初次 PoC 判断，是待评审目标，**不是已经实测的承诺**。如不达标，保留数据并评估布局/媒体/组件/框架成本，不篡改测量范围。

| 项目 | 建议目标 | 条件/口径 |
|---|---|---|
| 冷启动可输入 | p95 ≤ 3s | 无需等待模型、无大迁移；WebView2 已安装 |
| 本地文本提交到气泡 | p95 ≤ 150ms | 无网络依赖，包含本地 COMMIT；磁盘正常 |
| 输入反馈 | p95 ≤ 50ms | IME/文字输入，不加入人为打字延时 |
| 10 万历史单页 | p95 ≤ 200ms | 页长 P-DATA-01，keyset，冷/热缓存分别报 |
| ≥3 字符中文检索首屏 | p95 ≤ 500ms | D-03，匹配/无结果分别报，不含外部语义搜索 |
| 1～2 字符全范围检索 | 可取消，通常 ≤ 2s | 未完成必须说明范围；不靠缩短历史伪造快结果 |
| 空闲常驻内存 | 总 working set 目标 ≤ 200MiB | 1/4/8 actor 分开；报告 private bytes 与 24h 趋势 |
| 无任务空闲 CPU | 时间平均目标 ≤ 1% | 原生进程树口径；短峰值和采样频率另报 |
| 历史滚动/弹层 | 60Hz 下交互帧 p95 ≤ 16.7ms | 记录掉帧/long tasks，不能只平均 FPS |
| 24h 无任务常驻 | 无持续单调内存/任务增长、无隐含模型轮询 | 至少两段空闲稳定窗口比较及任务数采样 |
| 暂停反馈 | 本地状态更新 ≤ 100ms，立即阻止新请求 | 远端取消/结束另计，不承诺退款 |

10 万条消息不是一次渲染 10 万 DOM。媒体满负载峰值与空闲内存目标不同，解码预算不代表实际一定只用该内存。备份/迁移速度依数据和磁盘报告吞吐、峰值内存与暂停窗口，不虚构统一固定秒数。

## 7. 自然度与记忆评测

### 7.1 样本与控制变量

固定角色配置/SKILL、来源集和模型版本，覆盖日常闲聊、冷场、兴趣差异、长话题、引用、用户不参与、工具明确/模糊任务、新闻资料缺失和资料更正。建议每类至少 10 次独立运行，跨至少两个实际提供方；最终样本量按预算与统计误差确认。

区分自然停止与硬保护：自然度测试同时记录保护触发比例，不能把因为额度用尽而安静的场景当作模型主动沉默成功。硬保护永远开启，不为评测关闭安全。

### 7.2 指标

| 指标 | 定义 | 初次建议目标/解释 |
|---|---|---|
| 合法 decision | 有完整解析、业务合法、可执行或合法 observe | 合同 fixtures 100%；真实样本另报模型/schema/修复率 |
| 身份/事实归属 | 对带标准答案的主体和来源判断正确 | 目标 ≥95%；错归关键身份是阻断缺陷 |
| 来源撤回隔离 | 撤回后上下文、FTS、摘要、记忆、缓存无旧文 | 必须 100%，不能用平均分放过隐私泄漏 |
| 事实虚构 | 摘要/记忆出现源集中不存在的 claim | 关键事实 0 容忍；其他报告数量和类型 |
| 召回相关性 | 最终送入的记忆与当前固定场景相关 | 人工标注 precision 目标 ≥80%，同时报缺失重要事实 |
| 角色辨识/自然交流 | 隐去模型标签的独立评审 1～5 分 | 建议中位数 ≥4，不以“像人”掩盖事实错误 |
| 反复客服模板 | 无需求反复总结/列单/“还能帮你什么” | 分场景计数，比对基线；复杂工具回答允许结构化 |
| 沉默/自然结束 | 允许 observe 的合理场景、未触发保护前停止 | 需确有成功场景，报告分布而非强制统一沉默比例 |
| 撤回/错字 | 真实自然出现次数/消息数，按角色分类 | “极低”候选目标 ≤1%，长样本置信区间另报，不用随机注入凑指标 |
| 成本/有效交流 | 所有实际调用/usage/工具费用，包括未发言 | 成本与自然度同时报告，不只计算发出的气泡 |

用户可见的“拟人度”滑块不是精确概率控制。稀有事件样本不足时写“不足以估计”，不能零次观察后宣布概率为零。自主资料修改遵循 P-PROFILE-01，不因评测想看到效果而自动制造事件；用固定合法候选验证执行规则，再用真实场景评估模型是否提出修改。

盲评建议至少两名独立评审，记录分歧和评分 rubric；只有一名时明确局限。模型 judge 可辅助但不代替隐私/权限判定和人工体验评审；可运行 eval 与付费 judge 另需批准。
