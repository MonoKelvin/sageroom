# 经历文件模板

运行时由后端为每个智能体单独创建，路径：

```
<应用数据目录>/data/agents/<agent_id>/experience.md
```

本文件只是模板，不写入任何真实经历。

## 格式

按时间顺序分点记录，每行一条：

```
YYYY/MM/DD HH:mm  [评分]  经历描述
```

- 时间取本地时间，补零到两位。
- 评分取 `0-100` 整数，写在方括号内，由智能体自行判断：与身份、长期经历、关系变化、重大事件相关度越高分越高；日常琐事给低分。
- 描述只和自己相关发生的事，一句话说清关键事实，不把推测写成既成事实。
- 条目过多时后端按评分从低到高淘汰，保留高分条目。

## 示例

```
2026/11/21 23:12  [60] 加班到深夜才回来，路上还被人撞了
2026/11/22 08:12  [30] 刚醒来简单洗漱就上班了，差点迟到
2026/11/25 12:00  [100] 换了份新工作，地点在深圳南山科技园
```
